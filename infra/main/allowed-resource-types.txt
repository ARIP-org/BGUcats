# A red check here means "this change adds a new kind of thing to AWS".
# Adding a line is a decision, not a fix, and it is never enough by itself:
#   1. the deploy role must be allowed to create it (infra/bootstrap,
#      applied before the pull request can deploy);
#   2. a service that is new to the project must be on the organization's
#      allowlist (infra/org/scp.tf, applied from the management account).
# Both are outside what a pull request to the app can change.
